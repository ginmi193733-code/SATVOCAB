How to use on iPad:
1. Upload this folder to any HTTPS static host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the hosted URL in Safari on iPad.
3. Share -> Add to Home Screen.
4. Launch from the new icon.

The app works offline after the first successful load, and study progress is saved locally in Safari.
